# 知识画布 · 设计稿

状态：历史交互预览，保留供查阅，不作为当前工作台的实施规则。当前首页、板块职责、布局与扩展要求见[工作台核心布局设计](design/核心布局设计.md)。下文中的页面数量、导航、命名及内存保存方式仅描述该预览。

## 体验

默认为 80px 导航轨与宽阅读画布。今日只突出一个重点问题，两个延伸问题使用单行入口；最近探索仅在有记录时出现。去掉口号、插画、编号和并排卡片。热榜作为真实模式的独立渠道。研究结果用单列正文，局限说明折叠；点击引用时才出现证据侧栏。

四个视图：今日、探索、研究、知识库。用问题、来源、判断和探索记录组织内容；不以聊天轮次组织导航。刘看山只用于真正空白的知识库，不进入正文、头像或工作状态。

## 实现边界

本轮使用已有独立预览入口。原草稿文件保留，KnowledgeApp 为新的组合入口。界面模型、演示数据、状态控制器、页面和样式分开。

示例模式显示固定编辑样本，观点与证据逐项关联，所有来源标记为示例，无虚构外链。真实模式通过现有 API 获取热榜与研究会话；没有真实观点生成能力时，仅展示来源摘录与现有简报，不制造共识或统计值。模式切换清空当前研究与证据面板。

知识库在此稿中保存本次打开页面内的研究结果，页面明确说明刷新会清空。正式持久化继续由产品层拥有。本轮不增加数据 schema 或公共 Application 命令。

## 验收

- 首页默认没有助手侧栏；读正文时保留足够宽度。
- 示例标签可见；真实模式无示例热榜、虚假已连接或虚构分歧。
- 点击问题进入探索，选择来源进入研究，引用展开对应摘录，保存后可从知识库重新打开。
- 搜索具有加载、无结果、失败与重试；旧请求不能覆盖新问题。
- 浅深色可切换；窄屏导航保持可操作，证据用原生对话框呈现并支持 Escape。
- 类型检查、构建和关键交互检查通过；这不代表 Mastra 或真实知乎账号联调已完成。
