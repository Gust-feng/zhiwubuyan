# ADR-0004：知乎深度研究的证据契约与迭代执行

> 当前适用范围由 [ADR-0005](0005-deep-research-mvp-scope.md) 更新。来源真实性、模型分析与证据分离原则保留；独立中间产物、manifest、BriefRevision 和恢复机制已由精简方案覆盖。 下文保留决策历史，不能按其中被覆盖的清单开发。

日期：2026-09-13 · 状态：accepted（开发设计已确定，产品实现与真实接口验收待完成）。

## 背景

产品采用 Mastra Agent + Workflows，提供以知乎为主要资料来源的通用深度研究。既有接口多数返回摘要；知识库检索可能仅返回无原始条目标识的字符串。需要统一计划、取证、发现、补查和报告的契约，避免开发时假定全文、任意筛选、精确引用或自动恢复已经具备。

## 决策

1. 使用一个独立 ResearchTask 和一个版本化主 Workflow。阶段 Agent 负责结构化判断，确定性的检索、预算、去重、保存由应用命令执行。首版不引入多 Agent 调度系统。
2. ResearchPlanRevision 固定研究目标、资料范围、必答问题和预算；ResearchQuery 表达同一计划范围内的动态调查动作。改写查询不需要改计划；改变目标、私人资料范围或预算只能由用户命令产生新计划版本。
3. SourceSnapshot 继续是唯一证据载体，新增明确的内容完整度、来源定位精度及获取记录。检索响应中的字符串可以按“检索片段”引用，但不能伪装成已定位的原始文档。
4. ResearchFinding 是模型分析，必须关联快照、证据片段及支持关系；不能代替原始证据。ResearchEvaluation 保存模型覆盖判断与应用校验结果。模型建议不直接授予范围、预算或终态。
5. 报告沿用 BriefRevision。基础正文保持 conclusion/evidence/disagreements/gaps；研究元信息、冻结 manifest 引用及段落与 finding 的关联作为研究报告契约补充，不建立第二个 Report owner。
6. 产品保存请求、授权、控制意图、分析产物、外部调用记录和幂等回执。执行步骤、循环位置和恢复路径仍由 Mastra 保存；研究 status/stage 只读投影。
7. 首版以显式阶段调用完成研究：Agent 提出查询，Workflow 调用取证命令，Agent 分析结果。框架工具适配共用这些命令；后续允许步骤内工具探索时仍使用相同预算与授权入口。
8. 限定来源身份、时间与证据可得性。搜索摘要不得升级为全文；EditTime 不区分发布与修改时间时保留语义不确定性；昵称、赞同数和重复转引不能证明来源独立或结论真实。
9. 执行有限补查和有限修正，预留收尾预算。资料不足允许保存明确标注缺口的报告；无有效证据不生成事实性报告，保留任务与失败原因。
10. 暂停、取消和异常恢复先失效旧执行许可，再依赖公开框架入口推进。文档或隔离实验通过不等于产品生命周期不变量通过。

## 结果与取舍

标准研究流程可独立迭代，知乎适配保留真实数据差异，已有 Brief 与证据设施能够复用。代价是首版必须实现来源关联、调用预算与恢复回执，不能用一段长提示词替代。

当前不承诺搜索覆盖整个知乎、自动取得正文、统计代表性、无人工干预的未知调用重放或个人 OAuth 已达到发布条件。上述能力各有明确验收门槛，详见开发方案。
