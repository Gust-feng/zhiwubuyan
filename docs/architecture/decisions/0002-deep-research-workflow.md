# ADR-0002：Mastra 驱动的独立研究任务

> 当前适用范围由 [ADR-0005](0005-deep-research-mvp-scope.md) 更新。独立任务与 Mastra 执行原则保留；计划版本、暂停恢复、多执行尝试、manifest 和 BriefRevision 前置要求已被覆盖。 下文保留决策历史，不能按其中被覆盖的清单开发。

日期：2026-09-13 · 状态：实施设计；框架选择按 [ADR-0003](0003-mastra-foundation.md) 执行，具体 schema 随实现冻结。

## 背景

深度研究需要计划、反复取证、缺口评估、成稿和审阅，并支持查看进度、调整范围及中断后继续。知乎查询接口不负责保存研究状态。一次长聊天也不能成为研究进度的唯一事实来源。

## 决策

1. ResearchTask 是可独立创建的研究任务，关联 Research，不要求 Conversation。聊天与 CLI 只调用相同应用命令，研究步骤不进入聊天 Run 队列。
2. 使用 Mastra Workflow 表达固定研究阶段和有界补查循环；确定性步骤直接调用应用命令，需要规划、分析或撰写时调用 Mastra Agent。
3. Research owner 保存任务目标、版本化 Plan、权限范围、预算账本、来源快照和 finding；library 保存最终 BriefRevision。引用真实证据，不从模型历史恢复事实。
4. Mastra 保存执行步骤与 checkpoint。产品保存执行引用、派发/停止意图、控制版本和已提交操作回执，不再建立另一套可写的工作流阶段进度。
5. 外部任务状态是框架执行快照、产品控制意图与结果回执的投影；暂停/取消命令不直接改框架内部表，必须通过受支持的运行接口传播。
6. 第一版每个研究任务最多一个活动步骤，后台研究按有限并发派发。研究和聊天可以共享底层调用限额，但不能重复调度同一执行。
7. 保留 `manual_selection` 与 `scoped_research` 两种证据政策。普通简报使用用户选择的固定快照；深度研究在批准的来源范围内自动取证，写报告前冻结 evidence manifest。
8. 步骤提交绑定 taskId、计划版本、控制版本和 attempt。停止或更改范围先失效旧执行授权；旧结果不能推进当前研究或覆盖新成果。
9. 预算跨规划、步骤、模型/工具重试和继续执行累计。框架、provider 与应用重试不得形成未经计数的嵌套重放。
10. 报告使用既有成果写入口，来源以 `conversation_run` 或 `research_task` 判别联合记录。保存回执先于成功 checkpoint，恢复重复调用返回同一成果。

## 执行与恢复

计划生成也受创建请求中的预算和来源范围约束。默认生成计划后 suspend，用户可编辑后开始取证；用户已明确要求在给定范围直接执行时，不重复请求同一授权。

暂停停止后续工作，并尝试在受支持边界 suspend/取消当前执行。实际 checkpoint 未保存前不能显示已暂停。取消保留已保存证据与报告，不声称撤回上游请求。

异常退出后先核对框架快照和产品回执，任务显示 interrupted，等待显式继续。存在可恢复快照时恢复同一框架执行；框架不支持安全继续时，用已确认的阶段成果建立新的执行尝试，并保留原记录。不得通过聊天消息推断下一阶段或自动重发未确认外部操作。

计划变更只在没有活动执行时提交。收紧权限可在运行中立即撤销旧控制版本，并停止当前执行；完成收尾后再保存新计划与继续，防止旧请求提交。扩大范围或预算必须来自明确用户指令。

## API 与前端

公开入口为 createResearchTask、getResearchTask、updateResearchPlan、startResearchTask、pauseResearchTask、resumeResearchTask、cancelResearchTask。创建后返回任务身份，调用方不等待整个研究完成。

研究有独立 snapshot 与事件流，共享已有 HTTP/SSE 传输机制；不向前端暴露框架原始 run 类型。前端分别展示计划、真实进度、证据与成果。

聊天 Agent 启动研究时只得到任务引用，不在工具内等待研究完成，也不能递归调用自身。暂停研究不会占住聊天输入；归档会话不会隐式取消研究。

## 影响与验证

当前尚无已发布研究任务数据，不保留旧设计的兼容协议。深度研究复用现有来源和成果存储，不建立第二个资料库。

必须验证授权收紧与旧 attempt 交错、预算跨恢复累计、框架 suspend/resume、异常退出、成果回执与 checkpoint 不一致、取消后不继续派发以及引用 manifest 完整性。研究质量通过真实问题的证据、反例和条件覆盖衡量。
