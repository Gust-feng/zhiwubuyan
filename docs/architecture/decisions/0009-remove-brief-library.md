# ADR-0009：移除独立简报库入口

日期：2026-09-13 · 状态：accepted

## 背景

产品正在收敛为网页端的用户知识 Agent。独立的“简报库”只是把已完成研究任务再次列出，既重复研究任务的结果入口，也会形成一套与用户知识空间并行的成果归属。

## 决策

1. 从工作台导航、视图类型、页面渲染和相关样式中移除 `briefs` 视图。
2. 研究报告、来源和任务数据继续保留；报告从对应研究任务内直接读取，不因移除入口而删除历史数据或后端报告接口。
3. 现有普通研究简报命令暂不随本次 UI 变更删除；它是否继续作为内部能力，另行在应用层 owner 评估，不再以“简报库”作为产品入口。
4. 登录回跳或旧前端残留的 `briefs` 视图值不再恢复，统一回到首页，避免访问已删除的页面。

## 结果与取舍

- 顶层导航只承载首页、我的知乎、深度研究和众声，减少重复的成果入口。
- 用户仍可在研究过程中查看已保存报告；后续报告历史应并入用户知识空间或研究任务列表，而不是重新恢复一个独立简报库。
- 本次不迁移或删除已有研究数据，避免把产品入口调整误当成数据清理。
