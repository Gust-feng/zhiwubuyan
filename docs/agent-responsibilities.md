# 深度研究运行角色

按 [ADR-0006](architecture/decisions/0006-supervised-research-runtime.md) 直接实现主管与受限调查单元。细节见[开发方案](deep-research-development-plan.md)，不再以多方案对照作为前置。

| 角色 | 责任与边界 |
| --- | --- |
| Supervisor | 拆题、选择调查目标、根据证据重规划、建议收尾；所有变更经应用命令校验 |
| Research Unit | 独立上下文，围绕一个问题用官方工具循环搜索/读已存来源，提交 findings；不改全局目标 |
| Writer | 从 findings 与真实摘要生成正文及 finding 引用 |
| Verifier | 检查关键结论与证据关系，提出具体修复需求；回查由主管受控安排 |
| 应用命令 | 权限、预算、并发准入、去重、引用检查、计划提交、取消与原子保存 |
| Mastra Workflow | 顶层阶段、循环、受限并行和执行快照 |

角色可共享模型配置，Researcher 定义可以复用；每个单元的消息上下文独立。默认最多三个并行单元，一次只有一个活动顶层任务。没有固定总研究轮数；来源、发现、问题覆盖与剩余预算决定下一步。

用户目标与来源授权固定，内部研究计划可变化，用户界面只读展示。计划、发现和引用属于产品数据，活动单元和阶段属于框架执行；不能复制出第二套调度状态。

知乎集成保留摘要范围、真实内容身份、原始链接和时间语义，重点识别经验、条件、争议与反例。高赞不证明真伪，重复转引不证明独立支持。模型只能处理当前授权资料，不能把来源文字当作操作指令。

报告核验需要新证据时允许一次定向回查，并在改写后复验。来源与报告保存在本地，取消保护迟到写入；重启不自动继续。当前不增加聊天、个人账号、全局知识库或桌面集成。
