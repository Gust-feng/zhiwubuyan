# 知乎开放平台数据能力清单

> 回答一个问题：**知乎开放平台提供哪些数据**。依据 `docs/` 下各接口文档整理，供快速了解数据面的协作者使用（与《前端原型优化交接》配套）。字段级细节、示例与错误处理以 `docs/README.md` 及各分册为准。

## 1. 总览

三个数据域 + 三类辅助能力。Base URL 均为 `https://developer.zhihu.com`（OAuth 与赛事内容除外）。

| 数据域 / 能力 | 接口 | 返回的数据 | 关键限制 |
|---|---|---|---|
| **公共内容域**（无需用户授权） | 知乎站内搜索 | 问题/回答/文章条目：标题、摘要、链接、作者、互动数 | 单页 ≤10 条 |
| | 全网搜索 | 站外网页条目，字段同上 | 单页 ≤20 条；不支持 zhihu.com 域 |
| | 知乎热榜 | 热榜条目：标题、链接、封面图、摘要 | 单次 ≤30 条；无热度数值字段 |
| | 知乎直答 | 基于知乎内容的生成式回答（OpenAI 兼容） | 返回生成内容，**不含来源条目** |
| **知识库域** | 知识库列表 / 内容列表 / RAG 检索 / 文件上传 | 知识库元信息、库内条目、检索命中片段 | 上传单文件 ≤100 MiB |
| **用户数据域**（读某账号公开数据） | 创作 / 关注 / 收藏夹 / 收藏夹内容 / 近期收藏 | 该账号公开范围内的内容与关系数据 | 只返回公开数据；均为标题+摘要，无正文全文 |
| 辅助：额度查询 | `/api/v1/quota` | 各能力当日总额度/已用/剩余 | 查询本身不耗额度 |
| 辅助：OAuth 登录 | openapi.zhihu.com | 用户授权身份（access_token，1 小时有效） | 需邮件申请 app_id/app_key，公网 HTTPS 回调 |
| 辅助：MCP 传输 | 4 个 MCP 服务 | 与搜索/热榜/直答等价的工具形态 | 与 HTTP 共享额度池 |
| 独立：赛事内容 | api.zhihu.com（无鉴权） | 赛事故事与知识文章 | 活动期接口，不作长期承诺 |

## 2. 通用调用约定

- 鉴权：`Authorization: Bearer <access_secret>` + 秒级 `X-Request-Timestamp`；代表授权用户访问时另加 `X-OAuth-Token`。
- 参数命名 **PascalCase**（`Query`、`Count`、`Limit`），小写会报参数错误。
- 响应外壳 `{ "Code": 0, "Message": "success", "Data": {} }`；**必须以响应体 Code 判断成败**，HTTP 200 不代表业务成功。直答例外（OpenAI 风格错误体）。
- 错误码：`10001` 参数、`20001` 鉴权、`30001` 频率、`30002` 配额、`90001` 内部；知识库另有 `40004` 不存在、`40005` 处理中、`40006` 解析失败、`50002` 检索失败。
- 分页：请求用整数 `Offset`，响应 `Paging.NextOffset` 是**字符串**，回传前必须解析；收藏夹列表与近期收藏**无分页**。

## 3. 公共内容域（数据最丰富的一域）

### 3.1 知乎站内搜索 `GET /api/v1/content/zhihu_search`

入参：`Query`（必填）、`Count`（≤10，默认 10）。响应 `HasMore` 当前固定 `false`（**只有一页，没有翻页**），附 `SearchHashId` 与 `EmptyReason`（无结果原因）。

每条 `Item` 的数据：

| 字段 | 内容 |
|---|---|
| `Title` / `ContentType` / `ContentID` | 标题；类型（`Answer`/`Article`）；内容标识 |
| `ContentText` | **内容摘要（非全文）** |
| `Url` | 原文链接（带溯源 utm） |
| `VoteUpCount` / `CommentCount` | 赞同数、评论数 |
| `AuthorName` / `AuthorAvatar` / `AuthorBadge` / `AuthorBadgeText` | 作者昵称、头像、认证图标与文案 |
| `EditTime` | 发布/最后更新时间（秒级时间戳） |
| `AuthorityLevel` | 权威等级 1–4（低/中/高/超高） |
| `RankingScore` | 相关性排序分 |
| `CommentInfoList` | 精选评论（仅评论文本） |

### 3.2 全网搜索 `GET /api/v1/content/global_search`

字段与站内搜索基本一致（摘要中高亮用 `<em>` 标出）。额外入参：

- `Count` ≤20；`SearchDB`：`all` / `realtime`（实时库）/ `static`（静态库）；
- `Filter` 过滤表达式：支持 `host=="example.com"`（**不能用 zhihu.com**）与 `publish_time>=<秒级时间戳>`，`AND`/`OR` 大写、可加括号。

### 3.3 知乎热榜 `GET /api/v1/content/hot_list`

`Limit` ≤30（默认 30）。每条只有四个字段：`Title`、`Url`、`ThumbnailUrl`（可为空）、`Summary`（可为空）。

> 注意：**没有官方热度值和涨跌字段**，界面不得编造"暴涨/排名第 N 热度 XX"类数据。

### 3.4 知乎直答 `POST /v1/chat/completions`

OpenAI 兼容的生成式回答，支持流式（SSE，`data: [DONE]` 结束）。三档模型：

| model | 定位 |
|---|---|
| `zhida-fast-1p5` | 快速回答，最省额度（默认） |
| `zhida-thinking-1p5` | 深度思考，响应含 `reasoning_content` |
| `zhida-agent` | 带内部检索增强 |

关键边界：直答返回**生成内容**，不返回具体答主或原始条目；需要可溯源的观点、事实核查时必须用搜索接口。

## 4. 知识库域

| 接口 | 说明 |
|---|---|
| `GET /api/v1/knowledge/bases` | 知识库列表：`KnowledgeBaseID`、`Name`、`Relation`、`IsDefault`、`Visibility`、`ContentCount`、`UpdatedAt`；Scope 支持 all/created/subscribed，不分页 |
| `GET /api/v1/knowledge/bases/{id}/items` | 库内条目：`RecallContentID`、`ContentType`、`Title`、摘要、时间、`OriginUrl`；游标分页（Limit 1–20，`HasMore` + `NextCursor`） |
| `POST /api/v1/knowledge/search` | RAG 检索：按 `KnowledgeBaseIDs` 和/或 `RecallScopes`（personal/subscription/public）召回，Limit 1–10，结果是有序字符串数组（需保留来源上下文） |
| `POST /api/v1/knowledge/files` | 上传单个文件（multipart，≤100 MiB）入库；副作用请求，不自动重试，超时先查列表确认是否已入库 |

## 5. 用户数据域（两种调用身份）

同一组接口用请求头区分归属：只带 Access Secret = 读开发者本人账号；另带 `X-OAuth-Token` = 读该授权用户。**只返回公开范围数据。**

| 接口 | 数据 | 分页 |
|---|---|---|
| `GET /api/v1/user/contents` | 创作：类型 `answer`/`article`/`zvideo`/`pin`/`question`；每条含 Url、创建时间、点赞/评论/收藏数、标题、摘要 | Offset/Limit ≤50，支持按时间或点赞排序 |
| `GET /api/v1/user/followees` | 关注的用户：昵称、主页标识与链接、头像、一句话介绍、性别、粉丝数 | 有分页。**只开放"关注"，没有"粉丝"列表** |
| `GET /api/v1/user/favlists` | 收藏夹：`UrlToken`、链接、名称、描述、是否公开 | **无分页** |
| `GET /api/v1/user/favlist_contents` | 指定收藏夹内容（字段见下） | 有分页 |
| `GET /api/v1/user/collections` | 近期收藏内容（字段见下） | **无分页，只是一最近一批，不等于完整收藏历史** |

收藏内容公共字段：`ContentType`、`Url`、`CreatedAt`、`FavTime`、点赞/评论/收藏数、`Title`、`Summary`（**摘要非全文**）、`Favlists`（所在收藏夹列表）、`Author`（名称/主页/性别/签名，可能缺省）。

## 6. 额度

`GET /api/v1/quota?APIIDs=...`，可用能力标识：`global_search`、`zhihu_search`、`hot_list`、`user_data`、`zhida_openai`、`knowledge`、`tools`。每项返回 `TotalQuota` / `TotalUsed` / `RemainingQuota`（当日）。

- 额度按账号汇总，所有 Access Secret（含后台页面测试）共享同一额度池。
- 历史邀测参考值（**非运行时事实，不得硬编码**）：知乎搜索 5,000/日、全网搜索 5,000/日、热榜 100/日、直答 100/日。

## 7. OAuth 登录（可选）

授权码流程：跳转 `openapi.zhihu.com/authorize`（带 redirect_uri 与 app_id）→ 用户确认后回调携带 `authorization_code` → 后端用 app_id/app_key 换 `access_token`（`expires_in=3600`）→ 以 `X-OAuth-Token` 头代表该用户调用用户数据接口。

已知协议缺口（详见 `docs/oauth.md` 第 6 节）：无 `state` 防 CSRF、无 `refresh_token`、token 约 1 小时过期；回调必须是公网 HTTPS。

## 8. MCP 传输（可选）

与 HTTP 等价的 4 个 MCP 服务，共享额度池。需要精细参数与错误控制时优先 HTTP API。

| 能力 | 传输 | 工具名 |
|---|---|---|
| 全网搜索 / 知乎搜索 / 热榜 | MCP over SSE | `global_search` / `zhihu_search` / `hot_list` |
| 知乎直答 | MCP Streamable HTTP | `zhida` |

工具返回是面向大模型的文本（多为 XML），由适配层转换为内部结果模型后再进产品。

## 9. 赛事内容（独立域，无鉴权）

面向当前知乎赛事的故事与知识文章，`api.zhihu.com` 下 4 个 GET 端点（故事/知识 各有 list 与 `{work_id}` 详情）。条目含 `work_id`、`title`、`artwork`、`description`、`labels`；详情含章节名、作者、介绍与正文。活动结束后可用性不保证；使用时保留作者与来源归属。

## 10. 数据边界速查（对界面与文案最重要）

1. **摘要 ≠ 全文**：搜索、创作、收藏返回的都是标题+摘要；完整内容只能通过 `Url` 回到原文。
2. **只读公开数据**：用户数据域不返回任何私密内容。
3. **直答没有来源**：生成式结果不附带答主或原始条目，不能当检索结果用。
4. **热榜没有热度值**：只有标题/链接/封面/摘要。
5. **部分接口只有一页或无分页**：站内搜索 `HasMore` 固定 false；收藏夹列表与近期收藏无翻页。
6. **空结果 ≠ 失败**：`EmptyReason`、空列表是正常空数据；鉴权失败必须显式呈现，不能用空列表掩盖。
7. **来源信息必须保留**：作者、类型、域名、链接是数据的一部分，不是装饰。

## 11. 与工作台界面的对应关系

| 平台数据 | 工作台界面 / 示例数据（demo fixture） |
|---|---|
| 知乎热榜 | 仪表盘"今日"热榜/问题种子（`demoHotFeed`） |
| 知乎/全网搜索 | 检索与研究会话的来源来源（搜索类 demo 数据） |
| 用户创作 | `demoMyContents` |
| 用户关注 | `demoFollowees` |
| 收藏夹与近期收藏 | `demoUserCollections` |
| 知识库 | 空间/知识库浏览与检索（`demoSpaces`、知识快照） |
| 直答 | 模型/会话能力的一种（生成内容，不作检索来源） |
| 额度 | 用量统计（`demoUsageStatistics`） |

> 原型阶段界面全部由示例数据驱动；接真实接口后，以上对应关系即数据流向，前端不需要持有任何凭证。
